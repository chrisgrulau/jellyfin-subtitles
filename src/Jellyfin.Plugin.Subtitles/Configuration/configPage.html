Shoal Subtitles

Finds subtitles for videos that are missing them, checks candidates against the actual audio, and fixes their timing. Every change can be undone.

Results

Subtitle files beside your films and episodes are checked daily, and subtitles are found for videos that have none in your languages (Scheduled Tasks → Shoal). Corrections follow the timing setting below; every change keeps the original, and every added subtitle can be removed with Undo.

Speech-to-text

Used to check subtitles against what is actually said. Built-in runs on this server with no setup (slower, free); a local service is free and fast with a GPU; cloud services are fast but charge per minute of audio.

Services

Keys are stored on this server in a file only Jellyfin can read. They are never shown again, logged or included in exports; you can replace or clear them. Test sends one second of near-silence (for a paid service, a small fraction of a cent).

Built-in

Runs on this server's CPU. Model base (the default; about 90 MB with the program) or small (more accurate, slower; about 200 MB), set in the Model box above. Downloaded the first time it's needed, or when you press Test.
A speech-to-text service with an OpenAI-compatible API on this server or your network (for example a faster-whisper server, speaches, or the whisper.cpp server). Free, and fast with a GPU.

Deepgram

OpenAI

The built-in speech-to-text needs your permission before its first use. It downloads a Whisper program (whisper.cpp, built by this project) and a speech model: about 90 MB in total with the default model, about 200 MB with the small one. They come only over HTTPS from this project's GitHub releases. Each file is checked against a checksum built into the plugin before it runs, and again each time it starts. It runs on this server's CPU with low priority and a time limit, and nothing is sent anywhere.

Advanced settings
These settings change how results are judged. The defaults are tuned for good results; changing them without understanding the effect can make matches or timing worse.
